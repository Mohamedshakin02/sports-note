# Sports Note

Sports Note is a personal sports journal web application designed to help users store and manage their sports-related content in one place. The platform allows users to organize their sporting experiences, ideas, learning, and important information through a simple and user-friendly interface.

The application is designed for sports persons as well as general sports audiences who want to keep track of their sporting experiences and stay organized. Users can store memorable sports moments, upcoming fixtures, motivational quotes, sports techniques, and training sessions in their personal journal.

Sports Note includes five core features: Moments, Fixtures, Quotes, Techniques, and Sessions. The Moments feature allows users to store special sports memories such as exciting matches, personal achievements, or memorable events. The Fixtures feature allows users to save upcoming sports matches. The Quotes feature allows users to collect motivational quotes from players or coaches. The Techniques feature helps users record sports techniques in a step-by-step format. Finally, the Sessions feature allows users to document training sessions, workouts, and exercise routines.

The application also includes user authentication, Google authentication, protected routes, role-based access control, an admin panel, image uploads, and YouTube video integration. Users can create, edit, and delete their own content, while images are stored using Cloudinary.

## Features

* Personal sports journal for organizing moments, fixtures, quotes, techniques, and training sessions in one place
* Create and manage memorable sports moments, including personal achievements, matches, and important events
* Save upcoming fixtures and organize them based on their dates
* Collect motivational quotes from sports players and coaches
* Record sports techniques and skills using step-by-step instructions
* Document training sessions, workouts, and exercise routines
* User accounts with email and password authentication as well as Google login
* Personalized journal data with automatic default content for newly registered users
* Create, edit, and delete journal content with changes stored in the database
* Upload and store images for moments and quotes using Cloudinary
* Discover related sports videos through YouTube API integration
* Admin dashboard for managing registered user accounts
* Role-based access control and protected routes for secure user and admin access
* Responsive interface designed for desktop, tablet, and mobile devices
